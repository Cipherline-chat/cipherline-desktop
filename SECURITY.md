# Security Policy

If you've found a security issue in the Cipherline desktop client in this repo, or in the
live Cipherline service, we want to hear about it.

**Please report privately to [security@cipherline.chat](mailto:security@cipherline.chat).**
Do not open a public issue or pull request for a security vulnerability.

**What to expect:** we acknowledge your report within **48 hours** and give an initial
assessment within **5 business days**. You can also report through this repository's
[private vulnerability reporting](https://github.com/Cipherline-chat/cipherline-desktop/security/advisories/new).

See [cipherline.chat/security-disclosure](https://cipherline.chat/security-disclosure)
for our full disclosure policy, response commitments, and safe-harbor terms.

Fixes ship in a new stable release of the desktop app, built and signed by the
[release workflow](.github/workflows/release-stable.yml) in this repo.
